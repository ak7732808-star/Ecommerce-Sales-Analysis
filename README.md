# E-Commerce Sales Data Analysis

## Project Overview
This project analyzes sample e-commerce sales data using SQL Server, Microsoft Excel, and Python.

## Objectives
- Calculate total sales revenue and orders.
- Identify top-performing products and categories.
- Analyze city-wise sales.
- Understand monthly sales trends.
- Create charts and an Excel dashboard.

## Tools Used
- Microsoft Excel
- SQL Server
- Python
- Pandas
- Matplotlib

## Key Findings
- Total Revenue: Rs. 202,800
- Total Orders: 10
- Highest Revenue Category: Electronics
- Highest Revenue Product: Laptop
- Highest Revenue City: Madurai
- Highest Revenue Month: January 2026

## Project Files
- `sales_analysis.py` - Python analysis
- `Ecommerce_Sales_Analysis.xlsx` - Excel dataset and dashboard
- `Ecommerce_Sales_Analysis_Project_Report.docx` - Project report

## Conclusion
This project demonstrates how SQL, Excel, and Python can be used to analyze sales data and identify business insights.

Note: This is a sample dataset created for learning purposes.
